# 📁 Rename Folder to ManaMesh

## Instructions:

1. **Close VS Code completely** (the folder is currently in use)
2. Open PowerShell or File Explorer
3. Navigate to `D:\Repos`
4. Rename the folder from `mtg-online` to `ManaMesh`

### Option 1: Using File Explorer
- Right-click on `mtg-online` folder
- Select "Rename"
- Type `ManaMesh`
- Press Enter

### Option 2: Using PowerShell
```powershell
cd D:\Repos
Rename-Item -Path "mtg-online" -NewName "ManaMesh"
```

5. **Reopen VS Code** and open the new `ManaMesh` folder
6. **Delete this file** (RENAME_FOLDER.md) - it's no longer needed!
